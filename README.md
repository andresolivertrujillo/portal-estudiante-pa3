# Portal del Estudiante - PA3

## Descripcion

Portal web que permite a los estudiantes explorar el catalogo de cursos disponibles, ver el detalle de cada curso y gestionar su seleccion de cursos.

## Tecnologias usadas

- React 19
- React Router DOM 7
- Vite
- JavaScript ES6+
- CSS

## Instrucciones para instalar y ejecutar

1. Clonar el repositorio:

```bash
git clone https://github.com/andresolivertrujillo/portal-estudiante-pa3.git
```

2. Entrar a la carpeta:

```bash
cd portal-estudiante-pa3
```

3. Instalar dependencias:

```bash
npm install
```

4. Ejecutar el proyecto:

```bash
npm run dev
```

5. Abrir en el navegador:

```text
http://localhost:5173
```
